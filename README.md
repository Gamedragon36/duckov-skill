## 1. 설치 상태 / 켜는 방법

이미 게임 폴더에 설치되어 있습니다.

```
D:\Steam\steamapps\common\Escape from Duckov\Duckov_Data\Mods\Dskill\
    Dskill.dll
    info.ini
    config.ini      ← 게임을 한 번 실행하면 자동으로 생깁니다
```

**켜는 순서**

1. 게임 실행
2. 메인 메뉴 → **모드(Mods)** 메뉴
3. 목록에서 **Duckov Skill** 를 켜기
   - 새로 설치한 모드는 기본이 "꺼짐"입니다. 반드시 켜 주세요.
4. 기지나 레이드에 들어가면 스킬이 작동하기 시작합니다
5. **F6** 을 누르면 스킬 창이 열립니다 (ESC 또는 F6으로 닫기)
   - **F7** 키로 계열 전환, **제목줄을 마우스로 끌면** 창을 원하는 위치로 옮길 수 있습니다 (Tab 은 인벤토리 키와 겹쳐서 사용하지 않습니다)

**확인 방법 (게임 로그)**

`D:\Steam\steamapps\common\Escape from Duckov\latest.log` 를 열어 아래 문구를 찾아보세요.

- `[Dskill] 모드 로드 완료 v0.0.0 (스킬 창 키: F6)` → 정상 로드
- `[Dskill] 스킬 데이터를 불러왔습니다.` → 저장 데이터 읽기 성공
- `[Dskill] 이 캐릭터에 없는 스탯이라 효과가 적용되지 않습니다: XXX`
  → 그 스탯은 이 게임 버전에 없어서 그 효과만 빠집니다(다른 효과는 정상)

## 3-1. 로그라이크(계승) 시스템 — 다른 세이브가 이번 판을 돕습니다

**다른 세이브에서 키운 스킬 레벨이 이번에 플레이하는 세이브의 경험치 획득 속도를 올려줍니다.**

| 항목 | 내용 |
|---|---|
| 계산 방법 | **다른 슬롯들의 스킬 레벨 합계** (지금 플레이 중인 슬롯은 제외) |
| 보너스 | 다른 세이브의 레벨 1당 **경험치 +0.5%**, 최대 **+150%** |
| 계승 등급 | Lv.1~49 **입문** / 50~129 **초심** / 130~249 **단련** / 250~399 **숙련** / 400~599 **영웅** / 600+ **전설** |
| 화면 표시 | F6 창 상단에 `계승 영웅 (다른 세이브 2개 / Lv.420) → 경험치 +150%` |
| 게임 시작 | `[계승] 다른 세이브의 기록으로 경험치 +60% (숙련)` 알림 (세션당 1회) |
| 갱신 시점 | 슬롯 전환 · 레이드/기지 진입 시 자동 재계산 |
| 설정 | `config.ini` 의 `[meta]` 항목 |

```ini
[meta]
meta_enabled = true          # 계승 기능 사용 (true/false)
meta_bonus_per_level = 0.5   # 다른 세이브의 스킬 레벨 1당 경험치 +0.5%
meta_bonus_cap = 150         # 최대 보너스 (%)
```

**예시**: 다른 세이브에서 스킬 5개를 만렙(총 Lv.100) → 이번 판 경험치 **+50%**
> 이전 이름(TarkovSkills)으로 저장된 기록도 계승 계산에 포함됩니다.

## 4. 설정 파일 (config.ini)

게임을 한 번 실행하면 모드 폴더에 `config.ini`가 자동 생성됩니다.
메모장으로 열어 값을 바꾸고 **게임을 다시 시작**하면 적용됩니다.

```ini
[general]
max_level = 20          # 스킬 최대 레벨
xp_base = 300           # 1레벨에 필요한 경험치
xp_step = 65            # 레벨마다 늘어나는 경험치
xp_multiplier = 1.0     # 전체 경험치 배율 (0.5=절반, 2.0=두배)
hotkey = F6             # 스킬 창 여는 키
notify_levelup = true   # 레벨업 알림 표시

[skill_xp]
# 스킬별 경험치 배율 (0.5=절반 속도, 2.0=두배 속도)
strength = 1.0          # 근력
endurance = 1.0         # 지구력
...
```

**예시**

- 전체 성장을 2배 빠르게: `xp_multiplier = 2.0`
- 근력만 느리게: `strength = 0.5`
- 스킬 창 키를 F7로: `hotkey = F7`
- 레벨업 알림 끄기: `notify_levelup = false`

## 5. 지금 구현된 방식과 한계

| 항목 | 구현 방식 | 참고 |
|---|---|---|
| 수리 경험치 | 들고 있는 장비의 **내구도가 늘어난 양**을 감시 | 기지 **창고에 넣어둔** 아이템을 수리하면 경험치가 안 쌓일 수 있습니다 |
| 근접 전투 | **명중** 기준 (휘두른 횟수가 아님) | 빗나간 공격은 경험치 없음 |
| 흥정 만렙 효과 | 게임에 '가격' 스탯이 없어서 **판매 시 금액을 더 지급**하는 방식 | 결과적으로 +10% 이득 |
| 재장전 엘리트 | 캐릭터에 '재장전 시간' 스탯이 없어서 **재장전 속도 +10%**로 대체 | 효과는 사실상 동일 |
| 수리 엘리트 "가격 50% 상승" | 게임에 수리 가격 스탯이 없어 **미적용** | 내구도 감소 없음은 정상 적용 |
| 생존술 엘리트 | 출혈 버프가 걸리는 순간 **제거** | 결과적으로 출혈에 안 걸림 |
| 신진대사 엘리트 | 굶주림·갈증 버프를 **제거** | 결과적으로 피해 없음 |
| 신진대사 경험치 | **음식/물을 쓴 뒤 15초 이내**의 포만감·수분 증가만 인정 | 기지에서 잠만 자도 오르는 것을 막기 위함 |
| 구르기 | 게임의 대시 **쿨타임·스태미나 값을 직접 조절** (기본 0.5초 / 10) | 모드를 끄면 원래 값으로 자동 복구됩니다 |
| 하이드아웃 | 게임 내부의 **비공개 값**(상인 갱신 쿨타임, 채굴 작업량)을 **리플렉션**으로 조절 | 모드를 끄면 원래 값으로 복구됩니다. 게임 업데이트로 값 이름이 바뀌면 그 효과만 빠지고 경고 로그가 남습니다 |
| 농사(정원) 미지원 | 게임에 정원 코드·번역문·씨앗 아이템은 있으나 **어느 씬(레벨)에도 배치되어 있지 않아** 실제로 사용할 수 없습니다 (QA 확인) | 그래서 하이드아웃의 "농작물 수확" 경험치는 제거했습니다 |
| 스탯 대상 검증 (QA) | 게임이 **실제로 캐릭터에게서 읽는 스탯만** 효과로 사용합니다 | 방어 엘리트·은신 엘리트는 원래 값이 총기/총알 쪽에서 읽혀서 동작하지 않아, 동작하는 효과로 대체했습니다 |
| 생존술 "디버프 -30%" | 게임에 관련 스탯이 없어 **코드로 구현** (확률로 디버프 무효화) | 출혈 면역과 같은 방식입니다 |
| 야간시야 | **레이드에서만** 밤 시간 경험치가 쌓입니다 | 기지에서 밤에 가만히 있어도 오르는 것을 방지 |
| 인지/정찰 | **소리를 들을 때** 경험치 (1초에 최대 1회) | 시야·감지 거리는 안개(Fog of War)로 밝혀지는 범위를 넓힙니다 |
| 낚시 | 물고기(**Fish 태그**)를 실제로 획득할 때 경험치 | 낚시 능력이 높을수록 물고기와 씨름하는 시간이 늘어 쉬워집니다 |
| 제작 | 제작 완료 + 새 레시피 해금으로 경험치 | 추가 생산분은 게임의 아이템 생성 기능으로 지급됩니다 |
| 투척 거리 +% | 던진 폭발물의 **비행 속도를 높임** (사거리 = 속도의 제곱에 비례) | 목표 지점보다 더 멀리 날아갑니다 |
| 폭발물 즉시 폭발 | 폭발물의 **신관 시간(delay)을 0으로** 설정 | 30% 확률 (원하시면 조정 가능) |

## 6. 되돌리는 방법 (안전)

- **잠시 끄기**: 게임의 모드 메뉴에서 Duckov Skill 를 끄기
- **완전 삭제**: 아래 폴더를 지우면 끝 (게임 원본 파일은 건드리지 않았습니다)
  ```
  D:\Steam\steamapps\common\Escape from Duckov\Duckov_Data\Mods\Dskill
  ```
- 모드를 끄면 스탯 보너스가 즉시 제거되고, 세이브에 남아 있는 스킬 데이터는 다시 켜면 그대로 복구됩니다.
- ⚠️ 모드를 끈 상태에서 게임을 저장하면, 수리 관련 값은 **원래 값(1.0)** 으로 되돌려 놓습니다.

## 7. 개발 / 다시 빌드하는 방법

> **버전 정책**: 모드 버전은 **0.0.0 고정**입니다. 요청이 있을 때만 올립니다 (info.ini 의 version 과 코드의 Version 상수를 함께 변경).

```
cd "C:\any programs\duckov\duckov-skill"
dotnet build -c Release
```

빌드하면 자동으로 게임 모드 폴더에 복사됩니다 (csproj 의 `DeployMod` 항목).

**파일 구성**

| 파일 | 역할 |
|---|---|
| `ModBehaviour.cs` | 모드 시작/종료, 0.5초 주기 처리(이동·회복·신진대사·수리 감지) |
| `ModBehaviour.Handlers.cs` | 게임 이벤트 처리(피해/사망/사격/재장전/상태이상/거래) + 스킬 창 표시 |
| `ModBehaviour.Tools.cs` | 특수 스킬 처리(투척술 폭발물 가로채기, 파밍 감지 시간 단축, 구르기) |
| `ModBehaviour.Hideout.cs` | 하이드아웃 처리(기지 체류 경험치, 상인 쿨타임, 비트코인 채굴 시간) |
| `SkillDefs.cs` | 스킬 15종 정의 + 경험치 획득량 |
| `SkillSystem.cs` | 레벨/경험치 계산, 스탯 보너스 적용, 세이브 저장/불러오기 |
| `SkillWindow.cs` | F6 스킬 창 UI |
| `Config.cs` | config.ini 읽기/생성 |

**다음에 할 수 있는 일**

- 실제 플레이 후 수치 조정 (config.ini 또는 `SkillDefs.cs`)
- 스킬 창에 카테고리 필터/정렬 추가
- 창고 아이템 수리도 경험치에 포함 (별도 감시 필요)
