# Duckov Skill — 덕코프 스킬 성장 시스템

> 🤖 **이 모드는 AI 코딩 에이전트(Cline)와 협업해 제작되었습니다.**
> 코드·문서·번역은 AI 에이전트가 작성했고, 설계·밸런스 결정과 게임 내 검증은 제작자가 진행했습니다.
> (Steam 창작마당 규칙 5 — AI 생성 콘텐츠 표시)
>
> English description: [README.en.md](README.en.md)

## 소개

**Escape From Duckov** 에 타르코프식 **"행동으로 성장하는 스킬 시스템"** 을 추가하는 모드입니다.
총을 쏘고, 달리고, 루팅하고, 낚시하고, 제작하는 **모든 행동이 경험치**가 되고, 레벨이 오르면
그 스킬에 맞는 **영구 패시브 보너스**가 붙습니다.

## 주요 특징

| 항목 | 내용 |
|---|---|
| 스킬 | **24종** (신체 7 · 전투 6 · 실용 11) |
| 레벨 | 스킬마다 **Lv.0 ~ Lv.20** |
| 엘리트 | 만렙(Lv.20) 달성 시 **★엘리트** 전용 효과 추가 |
| 성장 | 플레이 중 행동으로 경험치 획득 → 자동 레벨업 |
| 적용 | 게임 자체의 **스탯 수정자 시스템** 사용 (게임 코드 패치 없음, Harmony 불필요) |
| 화면 | **F6** 스킬 창 (제목줄을 마우스로 끌어 이동), **F7** 계열 전환 · 각 스킬에 **경험치(현재/필요)** 와 **레벨당 수치** 표시 |

| 알림 | 레벨업 시 게임 자체 알림 표시 |
| 저장 | 경험치는 **세이브 슬롯별**로 저장 |
| 계승 | **다른 세이브**에서 키운 스킬이 이번 판의 경험치 획득 속도를 올려줌 (로그라이크) |
| 설정 | 게임 폴더의 `config.ini` 로 모든 수치 조절 |
| 조작 | **구르기 키(스페이스바)를 꾹 누르면** 쿨타임마다 자동으로 다시 구릅니다 (`dash_hold_repeat`, 기본 켜짐) |
| 언어 | 게임이 지원하는 **10개 언어** 지원 (한국어, English, 简体中文, 繁體中文, 日本語, Deutsch, Русский, Español, Français, Português-BR) — 게임에서 고른 언어를 자동으로 따르고(게임 설정이 없으면 OS 언어), `config.ini` 의 `language` 로 직접 지정할 수 있습니다 |

## 성장 속도

| 항목 | 값 |
|---|---|
| 레벨별 필요 경험치 | 1레벨 300점, 레벨마다 +100점 (300, 400, 500, … 2,200) |
| 만렙(20)까지 총 필요 | **25,000점** |
| 체감 속도 | 해당 행동만 계속했을 때 달리기 기준 약 **3.5시간** (일반 플레이에서는 더 오래 걸립니다) |

## 로그라이크(계승) 시스템

**다른 세이브에서 키운 스킬 레벨**이 이번에 플레이하는 세이브의 **경험치 획득 속도**를 올려줍니다.
(지금 플레이 중인 슬롯은 제외)

| 항목 | 내용 |
|---|---|
| 보너스 | 다른 세이브의 스킬 레벨 1당 **경험치 +0.5%**, 최대 **+150%** |
| 계승 등급 | Lv.1~49 입문 / 50~129 초심 / 130~249 단련 / 250~399 숙련 / 400~599 영웅 / 600+ 전설 |
| 표시 | F6 창 상단에 `계승 영웅 (다른 세이브 2개 / Lv.420) → 경험치 +150%` |
| 시작 알림 | `[계승] 다른 세이브의 기록으로 경험치 +60% (숙련)` (세션당 1회) |

**예시**: 다른 세이브에서 스킬 5개를 만렙(총 Lv.100) → 이번 판 경험치 **+50%**

## 설정 파일 (`config.ini`)

게임을 처음 실행하면 모드 폴더에 `config.ini` 가 자동 생성됩니다.
메모장으로 열어 값을 바꾸고 게임을 다시 시작하면 적용됩니다.

```ini
[general]
max_level = 20          # 스킬 최대 레벨
xp_base = 300           # 1레벨에 필요한 경험치
xp_step = 100           # 레벨마다 늘어나는 경험치
xp_multiplier = 1.0     # 전체 경험치 배율 (0.5=절반, 2.0=두배)
hotkey = F6             # 스킬 창 여는 키
notify_levelup = true   # 레벨업 알림 표시
dash_hold_repeat = true # 구르기 키를 꾹 누르면 쿨타임마다 자동으로 다시 구르기

[meta]
meta_enabled = true          # 로그라이크 계승 기능
meta_bonus_per_level = 0.5   # 다른 세이브의 레벨 1당 경험치 +0.5%
meta_bonus_cap = 150         # 최대 보너스 (%)

# true 로 두고 게임을 한 번 실행하면 모든 스킬 경험치가 0으로 초기화됩니다(끝나면 자동 false).
reset_skills = false

[skill_xp]
strength = 1.0          # 스킬별 경험치 배율 (0.5=절반 속도, 2.0=두배 속도)
endurance = 1.0
...
```

## 구현 참고 / 제한사항

| 항목 | 내용 |
|---|---|
| 게임 코드 패치 | **하지 않습니다** (Harmony 미사용). 게임의 스탯 수정자 시스템만 사용하고, 수정자도 자체 토큰으로 격리해 다른 모드와 충돌하지 않게 했습니다 |
| 스탯 대상 검증 | 게임이 **실제로 플레이어 캐릭터에게서 읽는 스탯만** 효과로 사용합니다. 총기/총알 쪽에서 읽히는 값은 동작하지 않아, 동작하는 대체 효과로 바꿨습니다(방어 엘리트·은신 엘리트) |
| 생존술 "디버프 -30%" | 게임에 해당 캐릭터 스탯이 없어 **코드로 구현**(확률로 디버프 무효화) |
| 농사(정원) | 게임에 정원 코드·번역문·씨앗 아이템은 있으나 **어느 씬에도 배치되어 있지 않아** 사용할 수 없습니다. 그래서 수확 경험치는 제외했습니다 |
| 낚시 | 물고기(`Fish` 태그) 아이템을 **실제로 획득**할 때 경험치 |
| 제작 | 추가 생산분은 게임 자체 아이템 생성 기능으로 지급 |
| 리플렉션 | 상인 쿨타임·비트코인 채굴 시간은 게임 내부 비공개 값이라 리플렉션으로 조절합니다. 게임 업데이트로 이름이 바뀌면 **그 효과만 빠지고 경고 로그**가 남습니다 |
| 저장 | 경험치는 **세이브 슬롯별**로 저장됩니다(세이브를 지우면 스킬도 삭제) |

## 빌드 방법

```powershell
cd "C:\any programs\duckov\duckov-skill"
dotnet build -c Release
```

- 대상 프레임워크 `netstandard2.1`, 게임 자체 어셈블리(`TeamSoda.*`, `ItemStatsSystem.dll`, `Unity*`)를 참조합니다
- `.csproj` 의 `DeployMod` 타깃이 빌드 후 DLL·`info.ini`·`preview.png` 를 `Duckov_Data\Mods\Dskill` 로 복사합니다
- 게임 설치 경로가 다르면 `.csproj` 의 `<DuckovPath>` 를 수정하세요
